Show the full details of an issue

Text output shows every frontmatter field, the body, and the branch divergence. JSON output holds
every field in one object.

Usage: tisket issue show [OPTIONS] <ID>

Arguments:
  <ID>
          Issue ID: the file name without .md, its 4-character prefix, or its slug

Options:
      --format <FORMAT>
          Output format (text or json)
          
          [default: text]
          [possible values: text, json]

      --root <ROOT>
          Tracker directory. Literal: the directory must hold tisket.yml; no walk, no fallback.
          Without it, the nearest tisket.yml at or above the cwd is used. With none, reads use the
          configured root tracker and a write needs --home

      --field <FIELD>
          Extract a single field value
          
          Valid fields: `title`, `status`, `priority`, `assignee`, `due_date`, `labels`,
          `depends_on`, `children`, `body`, `scratch`, `id`, `project`.
          
          With `--field`, the command prints only that field value. It adds no formatting and no
          labels. For a list field (`labels`, `depends_on`, `children`), it separates the values
          with a comma and a space.

      --home
          Act on the configured root tracker (`tisket store root`), wherever the command runs

  -h, --help
          Print help (see a summary with '-h')
