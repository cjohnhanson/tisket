Manage issues

Usage: tisket issue [OPTIONS] <COMMAND>

Commands:
  create  Create a new issue
  list    List issues
  show    Show the full details of an issue
  path    Print the file path of an issue, relative to the tracker directory (the one holding
          tisket.yml)
  edit    Edit the metadata or the body of an existing issue
  close   Close an issue
  reopen  Reopen a closed issue
  move    Move an issue to a different project
  help    Print this message or the help of the given subcommand(s)

Options:
      --root <ROOT>  Tracker directory. Literal: the directory must hold tisket.yml; no walk, no
                     fallback. Without it, the nearest tisket.yml at or above the cwd is used.
                     With none, reads use the configured root tracker and a write needs --home
      --home         Act on the configured root tracker (`tisket store root`), wherever the
                     command runs
  -h, --help         Print help
